# Script para Montar a Apresentacao

Use este roteiro para criar a apresentacao em PowerPoint, Google Slides, Canva ou Gamma.

## Prompt Para Gerar a Apresentacao

Crie uma apresentacao academica de 10 slides para um projeto PIM chamado "Sistema Web para Venda de Equipamentos Medicos e Cursos".

A apresentacao deve ter visual limpo, profissional e tecnologico, com foco em sistema web, e-commerce, banco de dados e area da saude. Use uma identidade visual com cores azul, branco, cinza e detalhes em verde ou roxo. Evite excesso de texto nos slides.

O objetivo da apresentacao e mostrar para uma banca a modelagem do banco de dados e o sistema web rodando.

Estruture os slides assim:

## Slide 1 - Titulo

Titulo:
Sistema Web para Venda de Equipamentos Medicos e Cursos

Subtitulo:
Projeto Integrado Multidisciplinar - PIM

Conteudo:
- Nome da instituicao
- Nome dos integrantes
- Curso e semestre

Visual:
Imagem ou icone relacionado a tecnologia, saude e e-commerce.

## Slide 2 - Objetivo do Projeto

Titulo:
Objetivo do Sistema

Conteudo:
- Desenvolver uma plataforma web para venda de equipamentos medicos e cursos.
- Permitir cadastro, login, compra e acompanhamento de pedidos.
- Disponibilizar painel administrativo para gestao do sistema.
- Controlar estoque de equipamentos e vagas em cursos.

Visual:
Fluxo simples mostrando Cliente -> Compra -> Pedido -> Administrador.

## Slide 3 - Funcionalidades do Cliente

Titulo:
Funcionalidades do Cliente

Conteudo:
- Cadastro e login
- Visualizacao do catalogo
- Detalhes de equipamentos e cursos
- Carrinho de compras
- Checkout com endereco
- Historico de pedidos
- Area de cursos adquiridos

Visual:
Cards ou icones representando usuario, carrinho, pedido e curso.

## Slide 4 - Funcionalidades do Administrador

Titulo:
Painel Administrativo

Conteudo:
- Gerenciamento de equipamentos
- Gerenciamento de cursos
- Visualizacao de alunos
- Gerenciamento de cupons promocionais
- Acompanhamento de pedidos
- Alteracao do status dos pedidos
- Restricao de acesso por perfil

Visual:
Imagem de dashboard ou icones de gestao.

## Slide 5 - Modelagem do Banco de Dados

Titulo:
Modelagem Entidade-Relacionamento

Conteudo:
Inserir o diagrama ER do projeto.

Texto curto:
O banco foi modelado para representar o fluxo de e-commerce e o fluxo de inscricoes em cursos.

Visual:
Usar o diagrama ER em destaque, ocupando a maior parte do slide.

## Slide 6 - Principais Entidades

Titulo:
Principais Tabelas e Relacionamentos

Conteudo:
- Users: usuarios clientes e administradores
- Products: equipamentos e cursos
- Orders: pedidos realizados
- OrderItems: itens do pedido
- PromoCodes: cupons promocionais
- CourseClasses: turmas de cursos
- Students: alunos cadastrados
- Enrollments: inscricoes em cursos

Visual:
Tabela simples ou blocos conectados.

## Slide 7 - Tecnologias Utilizadas

Titulo:
Tecnologias Utilizadas

Conteudo:
- Frontend: React, Vite e TypeScript
- Backend: ASP.NET Core
- Banco de dados: PostgreSQL/Supabase
- ORM: Entity Framework Core
- Autenticacao: JWT
- Controle de acesso: perfis Cliente e Admin

Visual:
Logos ou icones das tecnologias.

## Slide 8 - Fluxo de Compra

Titulo:
Fluxo Principal do Sistema

Conteudo:
1. Cliente acessa o catalogo
2. Adiciona equipamento ou curso ao carrinho
3. Informa endereco no checkout
4. Sistema cria o pedido
5. Estoque ou vagas sao atualizados
6. Admin acompanha o pedido

Visual:
Fluxograma horizontal com seis etapas.

## Slide 9 - Demonstracao do Sistema

Titulo:
Sistema Web Rodando

Conteudo:
Durante a demonstracao, mostrar:
- Catalogo de produtos e cursos
- Login de cliente
- Carrinho e checkout
- Pedido criado
- Area "Meus Cursos"
- Login de administrador
- Painel administrativo
- Controle de pedidos, alunos e cupons

Visual:
Espaco para prints do sistema ou texto "Demonstracao ao vivo".

## Slide 10 - Melhorias Futuras

Titulo:
Melhorias Futuras

Conteudo:
- Integracao com gateway de pagamento real
- Calculo de frete por CEP
- Integracao com transportadoras
- Envio automatico de e-mails
- Recuperacao de senha
- Emissao de nota fiscal
- Dashboard com metricas de vendas
- Upload real de imagens
- Avaliacoes de produtos e cursos
- Logs e auditoria administrativa

Texto final:
Essas melhorias aproximariam o sistema de um e-commerce real e totalmente funcional.

Visual:
Roadmap ou lista em formato de etapas futuras.

## Orientacoes de Design

- Usar pouco texto por slide.
- Preferir icones, diagramas e fluxos visuais.
- Usar fonte legivel.
- Evitar fundos muito escuros.
- Inserir prints reais do sistema nos slides 3, 4 e 9, se possivel.
- No slide 5, deixar o diagrama grande e facil de ler.
- Manter a apresentacao com visual consistente.

## Versao Curta Para IA de Slides

Crie uma apresentacao de 10 slides para uma banca academica do PIM sobre um sistema web de e-commerce para venda de equipamentos medicos e cursos. A apresentacao deve mostrar objetivo, funcionalidades do cliente, painel administrativo, modelagem do banco com DER, principais entidades, tecnologias utilizadas, fluxo de compra, demonstracao do sistema rodando e melhorias futuras para tornar o projeto um e-commerce real. Use visual profissional, limpo, com tema de saude e tecnologia. Pouco texto, bons icones e espaco para prints do sistema.
